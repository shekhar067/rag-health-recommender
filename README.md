# RAG-Health-Recommender

A simple Retrieval-Augmented Generation (RAG) pipeline for personalized health recommendations, combining BioBERT, FAISS, and a large language model (FLAN-T5).

## Features

- **Semantic Retrieval:** Uses BioBERT embeddings and FAISS for fast retrieval of relevant biomedical literature.
- **Natural Language Generation:** Answers user health questions using evidence from retrieved articles, generated by FLAN-T5.
- **Citations:** Provides sources for each recommendation.
